Remaining: native definition-table loading (the existing lazy initializer
still invents generic bounds), keeper-level removal/notification dispatch,

to preserve full host identities, without claiming native allocation order. Wider
floating intermediates improve arithmetic fidelity but are not an x87 bitwise
equivalence certificate. These limits must not be hidden by RECONSTRUCTED tags.
